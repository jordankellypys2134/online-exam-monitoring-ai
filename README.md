## Overview

AI Exam Monitoring System provides a web application for supervising students during remote exams. By combining webcam monitoring and AI-driven analysis, it can flag situations such as more than one face appearing on camera, frequent shifts in attention, visible mobile phones, and other behavior that may need assessment.

The platform supports exam administrators and education teams seeking an organized approach to remote assessment oversight. Alerts appear during the session to highlight unusual activity, and post-exam reports preserve detected events for subsequent review.

---

## Core Capabilities

- Monitor online exams through a participant's webcam
- Detect multiple faces during an examination
- Flag instances of looking away
- Detect mobile phone use
- Identify behavior that may be suspicious
- Show alerts as monitoring events occur
- Produce reports for reviewing exam sessions
- Run through a web browser without requiring a separate desktop application

## Frequently Asked Questions

### Which users can use AI Exam Monitoring System?

The system is intended for educators, educational institutions, and exam administrators running webcam-monitored online assessments.

### Is a webcam mandatory?

Yes. The application needs webcam access to observe visual events during an exam.

### What does the system monitor?

Its available detection features cover multiple faces, looking away, mobile phone usage, and additional behavior the system identifies as suspicious.

### How are session results provided?

After an exam, the application creates monitoring reports that can be opened for review.

### What is the update process?

Obtain the newest project files from the repository or use the published latest build, then redeploy or refresh the web application according to your hosting setup.

### What can I check when monitoring fails to begin?

Verify that the browser has permission to use the webcam, ensure the application is being served properly, and confirm that the camera is available on the device. For continued issues, inspect the browser developer console and the deployment configuration.

### Are monitoring options configurable?

Available settings are determined by the project configuration. Review the included application files and deployment environment to identify the options supported by this build.
